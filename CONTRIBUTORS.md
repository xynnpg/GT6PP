# Contributors

GT6PP exists because people share time, hardware, disc runs, and careful
testing. This file records human contributions; the commit history records the
code.

## Project owner

- **XYMPG ([@xynnpg](https://github.com/xynnpg))** - project owner, direction,
  requirements, hardware and disc access, RPCS3 oracle runs, visual acceptance,
  and release decisions.

## How to add yourself

Open a pull request that adds a line under **Contributors** with:

- your name or GitHub handle,
- what you contributed (code, analysis, testing, hardware, docs),
- whether you want to be contacted for review.

Please do not add game data, decryption keys, or recompiled game code to this
repository. See `README.md` and `LICENSE`.
